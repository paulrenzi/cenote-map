# Photo Attributions

Every third-party photo used on this site is listed below with its source.
Each photo links to its source page so readers can find higher-resolution
versions and additional context. To swap or remove a photo, edit
`data/photos.json` (or add a Wikimedia override in
`data/photo_overrides.json` and run `python fetch-photos.py`).
